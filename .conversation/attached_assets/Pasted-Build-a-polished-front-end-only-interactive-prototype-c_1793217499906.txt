Build a polished, front-end-only interactive prototype called "Confiance", a B2B SaaS platform that helps South African brands keep customers by building trust. Use React + Vite + React Router + Tailwind CSS + Recharts + lucide-react + framer-motion. No backend: use seeded mock data and shared in-memory React state (Context) so an action in one view updates the others live. Show a small "Simulated demo data. All names are fictional." badge in the footer of each view.

CONCEPT
Customer Loyalty = (Convenience + Price) x Trust, where Trust is built by Service Quality, Support and Transparency. Tagline: "Loyalty is built on trust." Brands run anonymous audits using creators, publish a live transparency log, monitor social media for public outcry with an AI agent, and give customers a community portal. Creators are one trusted channel, not the only one.

THREE COMPLETELY DIFFERENT EXPERIENCES
Start at a landing page ("/") with the Confiance logo (shield with a check mark), tagline and three large cards: Brand Dashboard, Creator Hub, Customer App. Each opens its own route with its own layout, fonts, colours and navigation. They must NOT share a sidebar or look alike. A small floating "Demo switcher" pill (bottom corner) lets the presenter jump between views and has a "Reset demo" button.

Charts: Trust Score line over 12 weeks; "Why customers leave" horizontal bar (Poor service 47%, Delivery or hidden costs 54%, Low trust, Weak support); cohort retention area chart, Control vs Confiance over 90 days; donut of tickets resolved by Trust Council peers vs staff. Show context: "Average net loss per new customer: R520".
- SOCIAL OUTCRY RADAR (the main selling point, make it prominent):
  * An "AI Trust Agent (simulated)" panel with a pulsing live indicator that says "Scanning TikTok, X, Instagram, Facebook, Reddit... " and a last-scan timestamp.
  * Top row: Public Sentiment gauge, "Trust at risk" score, Active outcries count, Reach in the last 24h.

DEMO FLOW (must work end to end, with toasts and live updates across the three views)
1. Brand: press "Simulate viral outcry" in the Radar (e.g. "Delivery delays in Gauteng"), and the Trust Score shows a predicted drop.
2. Brand: open the outcry, run the playbook: create a Transparency Log incident, then launch a verification audit.
3. Creator: a new mission appears. Accept it, complete it, and report the issue privately.
4. Brand: the issue shows as "Issue flagged". Log a fix publicly in the Transparency Log.
5. Creator: tap "Verify and endorse", which creates the co-host broadcast.
6. Customer: the Trust Board shows the fix and the customer earns points.
7. Brand: the outcry moves to "Contained" and the Trust Score recovers with an animated counter.

QUALITY BAR
Clean component structure with separate theme tokens per view, reusable Modal, Toast, Drawer and Badge components, accessible contrast and focus states, loading skeletons on first render, empty states, and smooth page transitions. Make each view feel like a different product made by the same company.
